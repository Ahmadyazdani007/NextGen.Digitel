# NextGen.Digitel — Official Website

> **Brand Tagline:** “Building Tomorrow. Digitally.”

A premium, modern, futuristic, and fully responsive website for **NextGen.Digitel**, a premier digital technology solutions agency specializing in custom software, intelligent automation, mobile apps, UI/UX design, and cloud architecture.

## 💻 Tech Stack & Architecture

- **Core:** React 18 with Vite
- **Styling:** Tailwind CSS with custom theme extensions, glassmorphism, and radial gradients
- **Icons:** Lucide React
- **Visuals:** Custom HTML5 60fps Canvas node & particle simulation
- **Typography:** Space Grotesk (headings) & Inter (body) via Google Fonts

## 🏃 Running the Project Locally

```powershell
# Install dependencies
npm.cmd install

# Start development server
npm.cmd run dev

# Build for production
npm.cmd run build

# Preview production build
npm.cmd run preview
```
